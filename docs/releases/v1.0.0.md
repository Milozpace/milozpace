# Milozpace v1.0.0

Milozpace 的首个公开稳定版本：一个从真实个人站中提纯、可以直接定制的本地优先静态站模板。

Milozpace's first stable public release: a local-first, fully static personal website starter distilled from a real-world site.

## 主要内容

- 首页、手记、生活、一言、关于与自定义 404，附三篇本地 Markdown 示例文章。
- 浅深色主题、主题持久化、响应式排版、克制的入场动效与 reduced-motion 支持。
- 文章封面、目录、阅读进度、字体切换、回到顶部和相邻文章导航。
- 以仓库内 Markdown、JSON 与本地图片为唯一内容来源，构建后得到完整静态站。
- 内容校验、TypeScript/ESLint、单元测试、浏览器验收和公开边界检查。
- 中文主文、英文摘要、架构、定制、隐私、许可与安全说明。

## 快速开始

需要 Node.js 20.19 或更高的 20.x，或者 Node.js 22.12 及以上版本。

```bash
npm ci
npm run dev
```

生成并预览可独立托管的静态站：

```bash
npm run build
npm run preview
```

## 发行边界

本发行版只包含公开 demo 内容、原创抽象插画、源码、测试和文档；不包含私人文章或照片、CMS、数据库、生产服务接入、部署配置、账号或凭据。

源代码和仓库内专门制作的 demo 内容采用 MIT License。Milozpace 名称与字标以及未包含在仓库中的个人身份资产不随源码授权；发布自己的版本前，请替换 `src/site.config.ts` 中的名称与标识。
